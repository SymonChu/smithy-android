# 05 · UI 结构

Compose + 单向数据流（ViewModel + StateFlow）。底部导航四个 Tab。

```
底部导航
├── 📁 文件     双窗口文件管理器
├── 🧰 工作台   APK 工程（分析 → 编辑 → 打包 → 装机）
├── 💬 对话     AI Agent
└── ⚙️ 设置     模型 / 权限 / 模块 / 编辑器
```

## 1. 文件 Tab（抄 MT管理器）
- 上下两个窗口，各自独立路径栈；顶部有「同步滚动 / 路径对齐 / 交换」按钮
- 长按文件 → 浮动菜单：打开方式 / 复制 / 移动 / 解压 / 压缩 / 签名 / 属性 / 计算哈希 / 打开为 APK 工程
- 直接进入 zip/apk 内部浏览，可就地增删改（无需解压）
- 支持滑动连选、反选、批量重命名（表达式）

## 2. 工作台 Tab（核心）

三段式布局：**顶部状态卡 / 中部内容区 / 底部动作条**

- **顶部状态卡**：应用图标、名称、包名、状态机徽章（`未解包 / 已解包 / 有改动(3) / 已重打包 / 已签名`）、签名信息
- **中部内容区**（横向标签）：
  - `概览` — 分析报告：权限列表、组件、dex 统计、大小分布、壳猜测
  - `代码` — dex 搜索结果 → 点进去看 Java（jadx 按需）或 smali，可直接编辑
  - `资源` — 资源表、图标、字符串、布局，支持多选批量替换
  - `改动` — PatchRecord 列表，每条可看 diff、可单次回退、可写"为什么改"
- **底部动作条**：常驻 `重打包` `签名` `安装`，未满足前置条件时置灰并提示原因

## 3. 对话 Tab
- 左侧抽屉：会话列表（按置顶/今天/昨天/更早分组）
- 消息流：用户 / 助手（含可折叠思考链）/ 工具调用卡片
- **工具调用卡片**：工具名 + 参数摘要 + 结果摘要 + 「展开详情」，写入类显示 diff
- **门控确认条**：AI 要写时，卡片变成 `[说明影响] [GO] [拒绝]`，GO 才执行
- 输入区：附件（选 APK / 选文件 / 截图）、模型切换、计划模式开关
- 顶部：当前绑定的 workspace 徽章（点开可切换/关闭）

## 4. 设置 Tab

> **实现现状（0.1.6 起）**：设置是「竖列菜单 → 整页」两级：菜单四行（外观 / AI 接口 / 权限 / 扩展），
> 每行右侧显示该页现状，点进去是带返回的一整页。下面这份是规划中的完整清单 ——
> 其中多套模型配置、MCP 服务端开关、编辑器配置、危险区**还没做**，菜单里不许出现空入口。
>
> **实现现状（0.1.7 起）**：工作台底部由「重打包 / 签名 / 安装」三个按钮改成**一键「打包并装机」**
> （分步动作降到次级一行）；打包签名后自动出**验证卡 + 产物卡**（放在「改动」标签顶部）；
> 概览页最前面是**体检卡**（打开包即出）。对话页输入框上方是**技能条**（体检 / 改文案 / 改包名 /
> 换图标 / 装机验证 + 「全部…」），技能只挂该流程用到的工具。

- 模型配置（多套，可测连通性；可指定"总结模型"）
- 权限引导：Shizuku（含安装引导）/ Root / 存储 / 通知 / 电池白名单
- 编辑器：字体、主题、行号、自动换行（sora-editor 配置）
- 信任模式：全询问 / 只问破坏性 / 全自动（不推荐，需二次确认）
- 模块管理：rootfs 模块、构建模块、本地模型 — 显示体积、按需下载
- MCP：服务端开关 + 端口、外部 MCP 列表
- 危险区：清空工作区、重置全部数据

## 5. 关键交互细节（决定好不好用）

1. **AI 与手动共用一套操作**：AI 改了东西，用户能在「改动」里看到同样的 diff 并可回退——不能出现"AI 改了什么不知道"。
2. **任何耗时操作都能取消**：解包/回编/签名/AI 循环全部可中断，不卡 UI。
3. **失败必须给下一步**：不是弹 "Error"，而是"该包资源表非常规，点这里换 apktool 路径重试"。
4. **进度可见**：重打包时显示阶段（解析资源 → 汇编 smali → 打包 → 对齐 → 签名）。
5. **大对象不崩 UI**：smali 大文件用 sora-editor 的增量渲染；列表全部分页/虚拟化。
6. **可选悬浮窗**：AI 长时间任务时显示状态（对齐 CodeForge），默认关闭。

## 6. 引导流程（首次启动）
1. 选工作区目录（SAF / 或 App 私有目录）
2. 检测 Shizuku，没有则给安装与激活引导（含 adb 命令）
3. 配置模型（可跳过，先当纯改包工具用）
4. 一个"改应用名 + 换图标 → 装机"的演示，让用户 3 分钟内看到闭环
