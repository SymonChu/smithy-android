# 01 · 范围与需求清单

优先级：**P0 = MVP 必须有**；P1 = 一个版本内补齐；P2 = 长期/可选。
状态列留空，开发时勾。

## A. APK 解析与查看

| # | 需求 | 优先级 |
|---|---|---|
| A1 | 打开 APK 并列出内部结构（dex / res / assets / lib / META-INF） | P0 |
| A2 | 解析 AndroidManifest：包名、版本、权限、Activity/Service/Receiver/Provider、导出组件 | P0 |
| A3 | 解析签名：v1/v2/v3 方案、证书主体、指纹（MD5/SHA1/SHA256）、是否 debug 签名 | P0 |
| A4 | dex 统计：类数、方法数（含 65536 溢出预警）、字符串数、各 dex 大小 | P0 |
| A5 | 资源查看：字符串表、图标、图片、颜色、布局 XML、ARSC 全表 | P0 |
| A6 | 加固/壳特征识别（常见壳的 so/类名特征） | P1 |
| A7 | split APK / XAPK / APKM / AAB 支持 | P1 |
| A8 | 生成可导出的"分析报告"（Markdown / JSON） | P1 |

## B. 代码层编辑

| # | 需求 | 优先级 |
|---|---|---|

| B2 | 单类反编译为可读 Java（jadx-core，按需，不全量） | P0 |

| B6 | 修改记录 + 撤销（diff 视图，可回退单次改动） | P1 |
