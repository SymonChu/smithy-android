# 00 · 总览

**项目名（工作名）**：Smithy
**一句话**：手机上的「APK 工程工作台 + AI 助手」——自己能改包，还能让 AI 改包。
**形态**：Android App（arm64），单机运行，不依赖任何闭源 App。

## 参考的三个产品，各自取什么

| 来源 | 取它的 |
|---|---|
| MT管理器 | APK 编辑链路（smali/资源/签名）、直接操作 zip、双窗口文件管理、Shizuku/Root 提权、插件化 |
| CAssistant | 全维度解析报告、可视化批量改包（图标/文案/包名）、一键重打包、零门槛 |
| CodeForge | AI Agent 闭环（工具调用+会话+记忆+角色）、MCP 双角色、可选构建环境、隧道、本地模型、语音、定时任务 |

## 核心价值主张（三条，写进产品首页）

1. **改包不必用电脑**：解包→改→回编→签名→装机，全在手机上闭环，秒级。
2. **AI 能真正动手**：不是聊天，是 AI 直接调用 `dex.search` / `smali.patch` / `apk.rebuild` / `apk.install` 干活，写操作前有门控。
3. **开放**：自带工具集以 MCP 服务端形式暴露，可被外部 AI（Claude/Cursor/Trae）接入；也能挂外部 MCP。

## 明确不做（边界，避免范围失控）

- ❌ 不做通用桌面级 IDE（不编译你项目的 Gradle 工程，除非装了可选 rootfs 模块）
- ❌ 不做游戏外挂/作弊工具形态的功能（不内置内存修改器）
- ❌ 不做云端账号体系（无登录、无云同步，纯本地）
- ❌ 不做应用商店/分发平台
- ❌ 不内置 Linux rootfs 作为默认能力（改为可选下载模块）

## 与参考产品的根本差异

- 比 MT管理器：**AI 原生 + 开源**，但长尾兼容性弱（见 08）
- 比 CAssistant：**不依赖闭源、工具集开放、可被外部 AI 调用**
- 比 CodeForge：**体积小 20 倍**（30MB vs 3GB），因为核心不是"编译安卓项目"而是"改包"
